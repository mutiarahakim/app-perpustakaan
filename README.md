# Aplikasi Perpustakaan (app-perpustakaan)

## Deskripsi Singkat
Aplikasi pengelolaan perpustakaan berbasis web yang dikembangkan menggunakan framework Laravel 12.

## Tujuan
Project ini dibuat untuk memenuhi penugasan praktikum mata kuliah Pemrograman Framework/Web.

## Cara Menjalankan Project Secara Lokal
1. Clone repository ini atau buka di folder lokal.
2. Jalankan perintah composer untuk mengunduh dependencies:

   composer install
